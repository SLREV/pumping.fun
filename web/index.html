Cara kerjanya

01

Isi form

Nama, ticker, deskripsi, gambar, plus dev buy. Gambar & metadata diunggah ke IPFS lewat API pump.fun.

02

Transaksi create_v2

Server membangun instruksi lewat @pump-fun/pump-sdk, menandatangani dengan wallet launcher, lalu mengirim ke Solana.

03

Curve hidup

Token langsung diperdagangkan di bonding curve. Begitu 85 SOL terkumpul, likuiditas pindah otomatis ke Raydium.

Pakai sebagai API

Endpoint yang sama dipakai dashboard ini. Cocok untuk bot Telegram/Discord.

GET/api/status

Network, wallet launcher, saldo, mode simulasi.

GET/api/coins

Riwayat launch + data contoh untuk papan.

POST/api/quote

Estimasi token & market cap untuk jumlah dev buy.

POST/api/launch

Buat coin (metadata + transaksi on-chain).

Pertanyaan yang sering muncul

Apakah ini butuh smart contract sendiri?

Tidak. Token pump.fun dibuat oleh program resmi 6EF8rrecthR5Dkzon8Nwu78hRvfCKubJ14M5uBEwF6P. Yang kamu butuhkan hanya klien yang membangun instruksi create_v2 — itu yang dilakukan src/launch.ts di repo ini.

Private key disimpan di mana?

Hanya di server (file data/launcher.json atau env LAUNCHER_SECRET_KEY), tidak pernah dikirim ke browser. Untuk produksi gunakan KMS/HSM dan batasi MAX_DEV_BUY_SOL.

Kenapa dashboard bilang "SIMULASI"?

Wallet launcher belum diset atau saldonya 0, jadi transaksi tidak dikirim ke blockchain. Semua alur (metadata, estimasi, UI) tetap berjalan supaya bisa dicoba tanpa risiko.

Bisa untuk devnet?

Bisa. Set NETWORK=devnet, RPC_URL devnet, lalu jalankan npm run wallet:new dan minta airdrop. Gunakan METADATA_PROVIDER=self karena IPFS pump.fun hanya untuk mainnet.

Berapa biayanya?

Sekitar 0.002–0.004 SOL untuk signature + rent account, ditambah dev buy (kalau ada) dan priority fee. pump.fun mengambil fee dari setiap transaksi trading, bukan dari pembuatan token.
